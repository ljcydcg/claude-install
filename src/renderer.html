Claude / Codex 桌面管理器

一键安装部署 Codex CLI 与 Claude Code CLI，并配置 base_url / key。项目目录：D:\claude-install

1. 安装路径

建议都放 D 盘，避免污染系统 Node 全局目录。

2. Codex / Claude Code API 配置

选择要配置的 CLI，然后填写对应的 base_url 与 key。

Codex CLI API 配置npm 包：@openai/codex待扫描
Claude Code API 配置npm 包：@anthropic-ai/claude-code待扫描

3. 操作

安装完成后会生成：安装根目录\ai-cli-env.cmd 与 安装根目录\ai-cli-env.sh，并把 npm 全局 prefix 写入用户 PATH。
